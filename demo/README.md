# InjaazhERP — AI-Native Enterprise ERP Template

[![Next.js](https://img.shields.io/badge/Next.js-14-black)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)](https://www.typescriptlang.org/)
[![Prisma](https://img.shields.io/badge/Prisma-ORM-5A67D8)](https://www.prisma.io/)
[![Gemini AI](https://img.shields.io/badge/Gemini-AI-orange)](https://deepmind.google/technologies/gemini/)

**InjaazhERP** is a comprehensive, production-ready enterprise resource planning solution built with the latest web technologies. Featuring 12 integrated modules and a centralized InjaazhAI brain, it provides unprecedented business intelligence and automation.

## 🚀 Key Modules
- **HRM**: Payroll, Attendance (SSE), Leaves, Performance.
- **CRM**: Lead Pipeline (Kanban), Contacts, Activity Tracking.
- **Inventory**: Multi-warehouse, Stock Movements, Low-stock Alerts.
- **Finance**: Chart of Accounts, Invoicing, Journal Entries, P&L.
- **Manufacturing**: BOM, Work Orders, Production Logs.
- **Projects**: Gantt Charts, Tasks, Time Logs, Budgeting.
- **AI Hub**: Conversational AI, Auto-insights, Forecasting.
- **Analytics**: Cross-module BI Dashboard, Custom Reports.
- **Settings**: Multi-tenant RBAC, Permission Matrix, Audit Logs.

## 🤖 AI Capabilities (Gemini 1.5 Pro)
- **Real-time Insights**: Automated cross-module business alerts.
- **Conversational Query**: Ask anything about your data in natural language.
- **Predictive Forecasting**: 3-month revenue and inventory predictions.
- **Auto-drafting**: AI-generated emails, reports, and proposals.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Database**: PostgreSQL (Prisma ORM)
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animations**: Framer Motion
- **Real-time**: Server-Sent Events (SSE)
- **Charts**: Recharts & Custom SVG

## ⚡ Quick Setup
1. Clone the repository.
2. Run `npm install`.
3. Set up your `.env` (use `.env.example`).
4. Run `npx prisma db push`.
5. Run `npm run seed` to initialize demo data.
6. Run `npm run dev`.
